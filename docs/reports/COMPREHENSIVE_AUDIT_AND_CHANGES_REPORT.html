2. Before vs. After Evolution Matrix

Domain Initial Prototype State Hardened Production State
JWT Token Lifecycle 24-hour expiration; static fallback secret Fixed 2-hour expiration; mandatory env secret; auto-logout
Patient Record Access (IDOR) Any user could view any record by modifying URL ID Fixed Patient-link and doctor-assignment checks; HTTP 403 Forbidden
Bulk Telemetry Harvesting Unrestricted access on GET /api/patients Fixed Database query scoped to authenticated role/identity
Vital Reading Bounds Missing vitals defaulted to 0 or 75; noisy spikes allowed Fixed Physiological bounds (HR 20-260, SpO2 50-100, Temp 32-43); zero fabrication
Alert Attribution & Lifecycle Unexplained threshold triggers; binary ack/unack Fixed ruleId, confidence, $R^2$ fit, resolve state with clinician reasons
Audit Log Immutability Mutable logs; susceptible to deletion/edits Fixed Permanent Mongoose pre-hooks block update/delete queries
Simulator Repeatability Unseeded random walk; unmanaged duplicate processes Fixed 7 seeded deterministic scenarios; PID lockfile; safe --stop
Evaluation Benchmark No benchmarks; data leakage risks Fixed Separate Tuning vs. Held-Out Evaluation partitions (0% leakage)

5. Disclaimers & Operational Notes

  • Illustrative Demonstration Rules: The alert threshold rules (Heart Rate > 120 bpm, SpO2 < 92%) are heuristic software demonstrations and have not undergone clinical trials or FDA / CE-MDR certification.
  • Database Encryption: Native WiredTiger encryption at rest requires MongoDB Enterprise. On Community Edition, OS-level encryption (BitLocker or LUKS) must be utilized.
  • Direct Admin Access: Immutability hooks operate in the Node.js tier; direct superuser access via mongosh can bypass application hooks.
